# Air Drums (CS50 Final Project)
Languages: C, Python, SQL (SQLite), HTML/JavaScript, Java.

## Run
    pip install flask
    gcc -o bpm bpm.c -lm
    python app.py            # open http://127.0.0.1:5000 (allow camera)
    javac StatsClient.java && java StatsClient   # leaderboard in terminal (server running)

Tips: good lighting, sit so both hands are visible, swing down firmly onto circles.
Tune SPEED in static/index.html if hits are too easy/hard.
